When giving API prompts/documentation, combine everything into a single code block so the user can copy-paste it all at once.

**Why:** User doesn't want to copy multiple separate blocks — prefers one combined output.

**How to apply:** Whenever sharing API details, endpoint docs, or prompts for frontend team, put it all in one single copyable block.
